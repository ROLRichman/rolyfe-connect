Private local chat

Pair one intended person below before sending. Messages remain in this tab only; nothing is queued for offline delivery.

    Pair two devices

    Open Connect on both devices while online once, then connect both to the same local network. Exchange the pairing files in person using Quick Share, AirDrop or another offline file transfer. Compare with the intended person before accepting; pairing files reveal local network details.

    1. Device A: tap Create invitation; send its file to B.
    2. Device B: import A's file, then tap Accept invitation; send the answer file to A.
    3. Device A: import B's file and tap Complete pairing. Both tap Enable speaker if needed.

    If the network drops, AirLink waits briefly for recovery. If it cannot recover, exchange fresh pairing files.

    Choose Create invitation on Device A only.

    Keep both original Connect tabs open during file exchange. Do not reload, open a new Connect tab, or navigate away. Pairing codes are session-specific. Reset both devices before starting over. Network client isolation or browser restrictions can prevent a direct connection.
    Help & offline test

    First load the HTTPS website on each device. Wait for the offline-ready message. Turn off cellular data and internet access, leaving local Wi-Fi enabled. Reload Connect, pair, and test speech in both directions. If a hotspot is used, keep it on even with mobile data disabled. Browser support varies; a native Android version is not included.

    Pair only with trusted people. WebRTC encrypts media and data in transit; this prototype has no independent identity verification, group access controls, or audited security.

      Setup guide · Android, iPhone, tablet & computer

      Android / Samsung

      Open this link in Chrome. Allow microphone access. Chrome menu (⋮) → Add to Home screen or Install app, if available. In Settings → Connections or Network & internet, choose Wi-Fi or hotspot. To test offline, disable mobile data and disconnect internet while keeping the local network active.

      iPhone / iPad

      Open in Safari. Tap Share → Add to Home Screen if available. Allow microphone access when prompted. Join the same Wi-Fi under Settings → Wi-Fi. Keep the page visible. Personal Hotspot may require mobile service; use a local router if needed.

      Amazon Fire tablet / other tablets

      Open in a browser supporting WebRTC and microphone permissions. Join the same Wi-Fi. If Add to Home Screen is unavailable, bookmark the page. Browser and microphone support vary.

      Windows / Mac / Chromebook

      Use Chrome, Edge, or Safari where supported. Bookmark this page (Ctrl+D or Command+D). Allow microphone permissions and connect to the same local network. Keep the tab open.

      Every device

      Load once online; confirm the offline cache is ready. A creates an invitation; B accepts and returns an answer; A completes pairing. Verify speech both ways, then test with internet disconnected but Wi-Fi enabled. A saved link does not keep a live connection. If a browser refuses offline loading, reconnect and try again.
